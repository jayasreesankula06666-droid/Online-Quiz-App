# Online Quiz App

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- 10 multiple-choice questions
- Instant answer feedback and explanations
- Score tracking and progress bar
- Final score and percentage
- Restart quiz button
- Responsive layout for mobile and desktop

## Project files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — quiz questions, scoring, and navigation

## Run locally
1. Download or extract the project ZIP.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `Online-Quiz-App`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After deployment completes, the site should be available at:
   `https://YOUR-USERNAME.github.io/Online-Quiz-App/`

## Customise questions
Edit the `questions` array in `script.js`. Each question includes a question string, four options, the zero-based index of the correct answer, and an explanation.
